# Tests

- `ClinicaPro.UnitTests`: pruebas de reglas puras del dominio.
- `ClinicaPro.IntegrationTests`: pruebas de integración de API/infraestructura.

bUnit y Playwright se incorporarán cuando existan componentes y flujos reales que justifiquen esas pruebas; no se dejan paquetes sin uso en la base inicial.
